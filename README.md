# 💼 Bank Transaction Analysis Dashboard | Power BI Project

## 📘 Project Overview
This project is a **Bank Transaction Analysis Dashboard** built using **Power BI**.  
It aims to analyze customer transactions, understand financial performance, assess risks, and identify valuable customer segments through data-driven insights.  

The goal is to demonstrate how **data visualization** and **business intelligence** can help banking institutions make informed decisions about profitability, credit risk, and customer engagement.

---

## 🎯 Objectives
- Analyze **total customer revenue** and **profitability**  
- Study **credit score distributions** across customers  
- Identify **high-risk customers** based on credit performance  
- Perform **RFM (Recency, Frequency, Monetary)** segmentation  
- Create an **interactive Power BI dashboard** for key financial KPIs  

---

## 🧩 Dataset
- **Source:** `bank_transactions.csv`  
- **Description:** The dataset includes details such as customer demographics, transaction records, credit scores, and revenue.  
- **Key Columns:**
  - Customer ID  
  - Transaction Amount  
  - Credit Score  
  - Risk Level  
  - Transaction Date  
  - Revenue  

---

## 🛠 Tools & Technologies
- **Power BI:** Dashboard design, modeling, and visualization  
- **Power Query:** Data cleaning and transformation  
- **DAX (Data Analysis Expressions):** Calculations and KPIs  
- **Excel / CSV:** Source data handling  

---

## 📊 Dashboard Highlights
🔹 **Revenue Analysis:** Total and average customer revenue  
🔹 **Credit Score Overview:** Distribution and segmentation  
🔹 **Risk Classification:** High, medium, and low-risk customer analysis  
🔹 **RFM Segmentation:** Identified customer loyalty based on transaction patterns  
🔹 **Performance Indicators:** Profitability and financial health metrics  

---

## 📈 Key Insights
- Most customers fall within the **medium-risk** credit range.  
- The **top 20% of customers** generate a major portion of the revenue.  
- RFM analysis revealed a small segment of **highly loyal customers**.  
- Visualization helped uncover **patterns between credit score and profitability**.
